Project 3 Full-Stack Database Application

This Flask application uses the normalized Student Assignment Tracker database and supports CRUD operations, relationship views, transaction logic, validation, and a small summary dashboard.

Open dashboard View relationships
What this app demonstrates
  • Multi-table CRUD for Students, Courses, Enrollments, Assignments, and Submissions.
  • Relationship handling across one-to-many and many-to-many tables.
  • A transaction that stores a submission, writes to an activity log, and recalculates progress.
  • Server-side validation to block missing values, duplicate records, and invalid scores.
  • Summary metrics built from aggregate SQL functions.
